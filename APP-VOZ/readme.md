# Sistema de Control Remoto por Voz usando Arduino, WiFi y Reconocimiento de Voz

[svg](https://github.com/l23171146/Sistemas-Programables/tree/main/APP-VOZ#sistema-de-control-remoto-por-voz-usando-arduino-wifi-y-reconocimiento-de-voz)

## Descripción

[svg](https://github.com/l23171146/Sistemas-Programables/tree/main/APP-VOZ#descripción)

El objetivo de esta práctica es desarrollar un sistema de control remoto de un motor DC mediante comandos de voz, utilizando un Arduino UNO R4 WiFi, comunicación WiFi, una aplicación desarrollada en MIT App Inventor y un módulo L298N.

## Objetivos de aprendizaje

[svg](https://github.com/l23171146/Sistemas-Programables/tree/main/APP-VOZ#objetivos-de-aprendizaje)

- Utilizar el Arduino UNO R4 WiFi para establecer comunicación mediante WiFi.
- Implementar el reconocimiento de voz mediante MIT App Inventor.
- Controlar el sentido de giro de un motor DC.
- Controlar la velocidad del motor mediante PWM.
- Utilizar comunicación HTTP entre la aplicación móvil y Arduino.

## Material utilizado

[svg](https://github.com/l23171146/Sistemas-Programables/tree/main/APP-VOZ#material-utilizado)

- Arduino UNO R4 WiFi
- Módulo L298N
- Motor DC con llanta
- Fuente de alimentación
- Cables Dupont
- Dispositivo móvil
- Red WiFi

## Conclusiones

[svg](https://github.com/l23171146/Sistemas-Programables/tree/main/APP-VOZ#conclusiones)

La práctica permitió implementar un sistema de control remoto por voz utilizando Arduino UNO R4 WiFi, comunicación HTTP y una aplicación desarrollada en MIT App Inventor. Se logró controlar el movimiento y la velocidad del motor mediante comandos de voz, comprobando el funcionamiento de la comunicación inalámbrica y del control PWM.

## Resultados

[svg](https://github.com/l23171146/Sistemas-Programables/tree/main/APP-VOZ#resultados)
